YEAR 4 AI GAME MAKER — FREE STATIC VERSION

What this is:
A public static version of the Year 4 AI Game Maker. Students do not need an account in the app.
The website itself can be hosted free on Cloudflare Pages.

IMPORTANT:
This version uses the Pollinations legacy text endpoint from the browser so there is no teacher API key in the files.
Because it is an anonymous/free service, it may be rate-limited, busy, or change over time. Do not enter student names,
emails, photos, school passwords, or other personal information.

DEPLOY FREE WITH CLOUDFLARE PAGES:
1. Create/sign in to a free Cloudflare account.
2. Go to Workers & Pages.
3. Create application -> Get started -> Drag and drop your files.
4. Name the project, e.g. year-4-ai-game-maker.
5. Upload this ZIP.
6. Click Deploy site.
7. Cloudflare will give you a public *.pages.dev address.

The site is static: index.html, styles.css and app.js. No build command is needed.

If the AI service stops accepting anonymous requests, the site will still load, but game generation will need a different AI backend.
